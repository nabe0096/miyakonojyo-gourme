## ハッシュタグの作り方

**毎回、業態に合わせて組み替える。前の店のタグを使い回さない。**

### 常に入れる（5つ）
```
#都城グルメ #宮崎グルメ #都城ランチ #宮崎ランチ #都城グルメ応援プロジェクト
```

### 業態に合わせて足す（3〜4つ）

| 業態 | 足すタグ |
|---|---|
| ハンバーガー | `#都城バーガー` `#ハンバーガー` `#バーガー巡り` |
| カフェ・喫茶 | `#都城カフェ` `#宮崎カフェ` `#カフェ巡り` |
| 古民家・和 | `#古民家カフェ` `#和食` |
| ラーメン | `#都城ラーメン` `#宮崎ラーメン` `#ラーメン巡り` |
| 居酒屋・夜 | `#都城居酒屋` `#宮崎居酒屋` |
| 洋食・イタリアン | `#都城イタリアン` `#洋食` |
| パン・スイーツ | `#都城パン屋` `#宮崎スイーツ` |

> ⚠️ 2026-08-20、ハンバーガー店の概要欄に `#古民家カフェ #都城カフェ #宮崎カフェ #カフェ巡り` が残っていた。
> **業態と合わないタグは、見つけている人に届かないうえ、内容と違う印象を与える。**必ず見直す。

## 注意

- 「📸今回撮影した写真はこちら」の直下に**店舗個別ページのURL**を入れる（本文だけで終わらせない）
- 店名の英字表記は、店舗の正式表記に合わせる（例：`BURGER HOUSE U`）
- 感想コメントは社長・keikoさんが書いたもの。**AIが書き足さない**
